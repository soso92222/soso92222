Étapes de création de l’app mobile (React Native)
1/Installation Expo CLI (plus simple pour démarrer)
npm install -g expo-cli

2️/ Créer l’app mobile
expo init mobile-minotor


 3/blank (JavaScript) comme template.

Lancer l’app
cd mobile-minotor
npm start


 4/Ça ouvre Expo et on peux scanner le QR code avec l’app Expo Go sur notre téléphone (iOS/Android).

Installation axios et navigation
npm install axios @react-navigation/native @react-navigation/stack
expo install react-native-screens react-native-safe-area-context
